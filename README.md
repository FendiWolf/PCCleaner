# 🧹 Windows PC Cleaner

A lightweight Python-based utility to help clean up unnecessary files, free disk space, and access quick system info — with a clean, modern graphical interface.

---

## ✨ Features

✅ **Temporary Files Cleanup**  
Remove local temp files, Windows Delivery Optimization leftovers, Prefetch data, system dumps, and more.

✅ **Download Folder Cleanup**  
Quickly clear out your Downloads folder if desired.

✅ **Microsoft Edge Browsing Cleanup**  
Detect if Edge is running and prompt the user before attempting to clean browsing data.

✅ **Recycle Bin Emptying**  
Empty the Windows Recycle Bin with a single click.

✅ **System Information**  
View quick system details:
- CPU
- RAM
- Motherboard
- GPU

✅ **Driver Tools**  
Detect your motherboard or GPU brand and automatically open the manufacturer’s driver/support website.

✅ **Modern Dark-Themed UI**  
Uses Tkinter with a dark theme for an inviting, uncluttered interface.

✅ **Standalone EXE Version Available**  
Built using PyInstaller so no Python installation is required for the packaged `.exe`.
